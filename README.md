## Project Description

A refactored JavaScript To-Do List application with modular code,
localStorage persistence, and automated unit tests.

## Technologies Used

- HTML5
- CSS3
- JavaScript ES Modules
- Node.js
- Vitest
- ESLint
- Prettier
- Git and GitHub

## Features

- Add, edit, complete and delete tasks.
- Filter tasks by status.
- Save tasks and filter preferences across refreshes.
- Shopping cart with quantity and total calculations.
- Five daily JavaScript challenges.
- Automated unit tests.

## How to Run

1. Clone this repository.
2. Run `npm install`.
3. Run `npm test`.
4. Run `npm run lint`.
5. Open the root `index.html` using VS Code Live Server.

## Lessons Learned

- JavaScript modules and code organization.
- Managing application state.
- Saving data using localStorage.
- Writing pure functions and unit tests.
- Using ESLint and Prettier.

## Challenges Faced

- Separating DOM code from business logic.
- Handling saved data safely.
- Configuring automated testing and linting.
